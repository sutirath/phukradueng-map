# แผนที่ภูกระดึง

แผนที่สถานที่เที่ยวและแผนทริปภูกระดึง ติดตั้งเป็นแอป (PWA) และใช้ออฟไลน์ได้

- เปิดบนมือถือแล้วกด "ติดตั้งแอป" (iPhone: แชร์ → เพิ่มไปยังหน้าจอโฮม)
- ผังแผนที่วาดตามแผนที่เส้นทางเดินเท้าของอุทยานแห่งชาติภูกระดึง ไม่ตรงมาตราส่วน

## เครดิตภาพถ่าย

ภาพถ่ายจาก Wikimedia Commons ครอบตัดและย่อขนาด รายชื่อผู้ถ่ายและสัญญาอนุญาตของแต่ละภาพอยู่ในหน้า "เตรียมตัว" ของแอป

## แผนที่จริง

ปุ่ม "แผนที่จริง" ในหน้าแผนที่ใช้ Leaflet กับภาพแผนที่ OpenTopoMap, ดาวเทียม Esri และ OpenStreetMap ต้องใช้อินเทอร์เน็ต ภาพที่เคยดูแล้วจะเก็บไว้ในเครื่องเพื่อใช้ออฟไลน์ได้บางส่วน
ตำแหน่งของแต่ละจุดและซำใช้พิกัดจาก Google Maps ที่รวบรวมไว้ (ยกเว้นน้ำตกถ้ำสอใต้ที่เป็นค่าประมาณ) เส้นประบนทางขึ้นเป็นการต่อจุดซำ ไม่ใช่เส้นทางเดินจริง
