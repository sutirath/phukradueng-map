# แผนที่ภูกระดึง

แผนที่สถานที่เที่ยวและแผนทริปภูกระดึง ติดตั้งเป็นแอป (PWA) และใช้ออฟไลน์ได้

- เปิดบนมือถือแล้วกด "ติดตั้งแอป" (iPhone: แชร์ → เพิ่มไปยังหน้าจอโฮม)
- ผังแผนที่วาดตามแผนที่เส้นทางเดินเท้าของอุทยานแห่งชาติภูกระดึง ไม่ตรงมาตราส่วน

## เครดิตภาพถ่าย

ภาพถ่ายจาก Wikimedia Commons ครอบตัดและย่อขนาด รายชื่อผู้ถ่ายและสัญญาอนุญาตของแต่ละภาพอยู่ในหน้า "เตรียมตัว" ของแอป
